BACKGROUND MUSIC PLACEMENT:
To have the official song "Idhar Zara Sa Dekh Lo" by Shikhar Yashica play in this application:
1. Place the audio file here:
   /public/audio/idhar_zara_sa_dekh_lo.mp3

2. The application is pre-configured to look for this exact path (/audio/idhar_zara_sa_dekh_lo.mp3).
3. If this file is not present, the app automatically switches to an authentic synthesized Indian ambient Raag/Tanpura harmonic meditation soundscape via Web Audio API, so there is never silence.
4. You can also click the top-right music icon in the application to select any local audio file on your device at runtime.
